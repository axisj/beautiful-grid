# Contributing to BeautifulGrid

Thank you for helping improve BeautifulGrid.

1. Search existing issues before opening a new one.
2. Include a minimal reproduction for bugs whenever possible.
3. Keep pull requests focused on one outcome.
4. Run `npm run verify:library` and the relevant site checks before submitting.
5. Preserve the public `BGrid*`, `bgrid-*`, and `--bgrid-*` naming conventions.

By submitting a contribution, you agree that it may be distributed under the Apache License 2.0.
